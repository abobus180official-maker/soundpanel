# SoundPanel

Звуковая панель для Windows в духе Soundpad: список звуков, глобальные горячие клавиши,
воспроизведение в выбранное устройство и подмешивание микрофона.

## Возможности

- Тёмный интерфейс: список звуков с номером, горячей клавишей, названием и длительностью.
- Воспроизведение по клику или глобальной горячей клавише (по умолчанию Ctrl+1…Ctrl+9, Ctrl+0).
- Зацикливание и повторное нажатие для остановки, режим «только один звук».
- Громкость звуков и микрофона отдельно, индикаторы уровня, кнопка отключения микрофона.
- Осциллограмма играющего звука с прогрессом.
- Добавление файлов и папок, перетаскивание, переименование, порядок, удаление.
- Сохранение плейлиста и настроек в `%APPDATA%\SoundPanel\config.json`.

Поддерживаемые форматы: wav, mp3, ogg, flac, aiff, opus (через libsndfile).

## Передача звуков в голосовой чат

1. Установите виртуальный кабель (например, VB-Audio Virtual Cable).
2. В SoundPanel в поле «Выход» выберите `CABLE Input`, в поле «Микрофон» — свой микрофон.
3. В Discord/игре выберите микрофоном `CABLE Output`.

Тогда собеседники слышат и ваш голос, и звуки из панели. Без виртуального кабеля
звуки просто идут в выбранные колонки/наушники.

## Запуск из исходников

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Сборка exe

```
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller --noconfirm --clean --windowed --onedir --name SoundPanel ^
  --distpath dist --workpath build\work --specpath build main.py
```

Готовая сборка: `dist\SoundPanel\SoundPanel.exe`.

## Горячие клавиши

Клик по ячейке «Клавиша» или пункт меню «Назначить клавишу…» открывает окно захвата:
нажмите нужное сочетание (поддерживаются Ctrl/Alt/Shift/Win, F-клавиши, цифры, numpad).

## Заметки

- Ошибки пишутся в `%APPDATA%\SoundPanel\error.log`.
- Аудиоустройства переоткрываются при смене выбора; при смене частоты дискретизации
  библиотека перезагружается автоматически.
